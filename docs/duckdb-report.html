v1.5.5 的关键修复包括：128 位 DECIMAL 在多行组 RETURN_STATS 下 min/max 交换的正确性修复 （#23693）、多起崩溃/死锁/越界读修复（#23351、#23861）、v1.5.0+ 存储启用 ALP/ALP_RD 压缩 （更小块体积，#23483）、ADBC 改进（duckdb:// URI、Statistics API）[3][8]。

向前看 · v2.0 预览（2026-08-17） 官方预览列出：DuckDB as a server、触发器、VARIANT 类型、异步 I/O、新 SQL 解析器、新存储格式； Quack 客户端/服务端协议转正并引入 CONNECT 语句。v2.0 由 v1.5 以来超过 10,000 次提交构建[5]。

02核心特性：1.5 "Variegata"（v1.5.0，2026-03-09）

  • 重做 CLI 客户端——新配色、显示当前库/Schema 的动态提示符、超 50 行结果分页、_ 引用上次结果
  • 原生 VARIANT 类型——类型化二进制半结构化存储（区别于文本承载的 JSON），配套 variant_typeof/variant_extract，Parquet VARIANT 支持（含 shredding）
  • 内置 GEOMETRY 类型
  • 实验性 PEG 解析器——更好的补全与报错、可被扩展的语法；官方计划"下一个版本"转默认
  • 生态与网络——httpfs 切换 curl 后端；DuckLake spec v0.4、Delta/Unity 写入改进、 Iceberg CREATE TABLE 属性；新增 read_duckdb；Azure 写入；ODBC scanner 扩展[4]
